# DEFENSE_LOG.md

핵심 설계 승인 직후와 중요한 구현·검증 완료 시 해당 항목을 갱신한다. 실제 확인한 사실에 코드 위치(`파일:줄`) 또는 실행 근거를 붙인다. 아직 구현하지 않았으면 **미구현**, 확인하지 않았으면 **미검증**, 적용할 구조가 없으면 **해당 없음**으로 표시한다. 핵심 판단과 흐름을 중심으로 기록하고, 시간순 작업 내역은 `WORKLOG.md`를 참조한다.

## 핵심 설계 결정

핵심 결정마다 한 항목을 작성한다.

- 결정할 문제와 관련 요구사항
- 선택한 방식과 검토한 대안, 각 방식의 장단점과 trade-off
- 선택 이유와 이를 뒷받침하는 근거
- 사용자 승인 여부와 근거(확인한 답변 또는 기록 위치)
- 실제 구현 위치와 검증 방법·결과
